# Suporte

Use GitHub Issues para bugs reproduzíveis e propostas delimitadas. Inclua versão ou commit, sistema
operacional, versão do Node, passos de reprodução, comportamento esperado e evidência relevante.

Perguntas sobre vulnerabilidades devem seguir [SECURITY.md](SECURITY.md). A série `0.x` recebe
suporte apenas na versão mais recente da branch principal.
